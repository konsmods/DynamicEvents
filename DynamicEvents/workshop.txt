description=[h1]Dynamic Event Framework (DEF)[/h1]
description=
description=Tired of the same empty roads and forests? Want more than just the Heli Event or Gunshots? You, my friend, are in the right place!
description=
description=Dynamic Event Framework is a world event framework for B42 with Multiplayer in mind. While you survive, stuff can happen across the map, not only on world creation: a military convoy ambushed on the highway, a heli that came down in the woods, and whatever else people cook up for it. Some events you will be able to hear, some will be announced on the radio, some will be hidden away in order to incentivise exploration!
description=
description=[b]What this framework provides:[/b]
description=[list]
description=[*]Scheduler - using the sandbox settings, we can set frequency of events, weights for certain events and cooldown timers to customize and balance the experience
description=[*]Event Manager - due to engine limitations objects cannot spawn outside the player's render distance, so we circumvent that by queuing up event spawns (loot, vehicles, zombies, etc.) up until a player enters the required radius
description=[*]Helper functions - so you do not need to look up deprecated API functions, the framework provides functions for the most common things you'd want to spawn (more coming!)
description=[*]Events can be telegraphed by sound (like the vanilla Heli) and/or emergency radio broadcasts so you can go looking on purpose
description=[*]Full sandbox control: there are a lot more settings and I will add a lot more in the upcoming versions
description=[*]Every event has its own on/off toggle, and each can carry optional mod dependencies (skipped automatically if you don't have them)
description=[*]All spawns are tracked, so admins can list, jump to and clear any event
description=[*]Persistent and self-managing - events survive restarts; each can stay until an admin clears it, or auto-clear after a set lifetime so the location frees up for future events
description=[/list]
description=
description=[b]Check out:[/b]
description=[list]
description=[*]Dynamic Events Content mod - there you can find a few sample events I've created, as well as some documentation on making your own and admin commands for management
description=[/list]
description=
description=[b]For modders:[/b] events are plain Lua files. Copy EXAMPLE.lua, drop in your id, locations and a spawn function, and use the ready-made helpers - SpawnVehicle, SpawnZombies, SpawnHorde, SpawnLoot, SpawnContainer, fire, smoke, scorch marks. Cleanup, tracking and persistence are handled for you, you just describe whatever you can come up with!
